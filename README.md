# Rishi Dandibhotla - Flutter Portfolio

A responsive Flutter portfolio for the UI internal exam, visually matched to the three supplied reference screenshots.

## Pages
- Home Page
- About Me Page
- My Projects Page

## UI details
- Same blue top app bar style and centered headings as the reference.
- Same centered home profile layout with lavender circular avatar placeholder.
- Same lavender About Me card, spacing, button shape and shadows.
- Same white project cards with blue titles and short descriptions.
- Back navigation between pages.
- Responsive scrolling/layout for smaller screens.

## Projects
- Hurestic_programing
- Dynamic_programming
- RISHI
- TurboScribe
